# ByahengPabama — online demo

**Live demo:** https://islawqt.github.io/byahengpabama-demo/

This is a browser-only demo of **ByahengPabama**, a capstone project at STI College Valencia: a bus tracking and fare matrix system for Pabama Corporation's CDO Agora Terminal ↔ Kibawe route.

> This is a student project with sample data. It is **not** an official Pabama Corporation website.

## What you can try

| Page | What it shows |
| --- | --- |
| Landing page | Buses on the road, announcements, and how the system works |
| Track a bus | Buses coming to your stop with arrival estimates, regular and discounted fares, and the route line |
| Announcements | The bulletin board, with category filters |
| Staff log in | Use one of the demo accounts below |
| Line Inspector | Report a bus at a checkpoint, then see it on the passenger page |
| Admin | Bus tracking dashboard, analytics (planned for Increment 4), buses, routes and fares, bulletins, accounts, and settings |

Every page can be switched between **English and Filipino** (EN | FIL) and between light and dark themes.

## How the demo works

The real system is a Laravel app with a MySQL database. GitHub Pages can only host plain files, so this demo works differently:

- **Same look.** It uses the real app's CSS, layouts, and wording, including its Filipino phrases.
- **Same rules.** It uses the same rules as the app's `BusTracker` and `FareCalculator` for statuses, arrival estimates, and fares.
- **Simulated buses.** Eleven buses run between the terminals around the clock. A fictional Line Inspector "reports" each bus at every checkpoint, and about 3% of reports are missed on purpose, the way some are in real life.
- **Changes stay in your browser.** Changes you make (new reports, buses, posts, fares, and settings) are saved in your browser only (`localStorage`). Other visitors don't see them. **Reset demo** in the yellow bar restores the sample data.

## Files

- `*.html`: page shells, generated by `tools/make_pages.py`.
- `assets/app.css`: the app's compiled stylesheet.
- `assets/js/`: the demo.
  - `store.js`: sample data.
  - `sim.js`: simulation and tracking rules.
  - `pages-*.js`: the pages.
  - `actions.js`: the forms.
